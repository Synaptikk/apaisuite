APAISuite Privacy Policy

Last updated 19 August 2026 · Applies to the APAISuite Chrome extension

APAISuite is a workbench for Walmart Asset Protection investigators. It reads dashboards and internal tools you are already signed in to, and assembles the results in one place so a case can be worked without twelve open tabs.

This policy describes exactly what the extension collects, what it transmits, and where that data goes. It is written against the source code rather than from a template, and it covers the version published on the Chrome Web Store.

The short version

Almost everything stays on your computer. Captured dashboard rows, case notes, reports and settings are held in the browser's local extension storage and are never uploaded.

Four features are exceptions, and each one transmits only because sending the data is the feature. They are listed in full below.

Nothing is sold, shared with advertisers, or used to build a profile of you.

What the extension sends, and where

These are the only cases in which data leaves your browser to a server operated by the developer or by a service acting on the developer's behalf.

FeatureWhat is sentWhere it goesWhy
AurorBuddy
case activity logging		 Your name, work email, Auror user id, store, market and job title, together with the Auror event identifiers you act on, the status of each import workflow, and counts of actions taken. A Google Firestore database operated by the developer (project aurorbuddy). So the team's case activity can be reported on across investigators. This is the module's purpose; it is not incidental telemetry.
Closing List
roster sharing		 Associate names, shift start and end times, job label, called-off flag, store number and business date. A Google Firestore database operated by the developer (project managerchecklist). So the Closing Manager Checklist web app shows the same roster live on another device for the same store and date.
QRCallBox / Workvivo
posting on your behalf		 Your Workvivo chat access token, plus your store number and the channel name you selected. qrcallbox.com, a backend operated by the developer. The server cannot sign in to Workvivo itself, because sign-in requires an MFA push to you. Your browser signs in normally and hands the resulting token to the server so QR scan alerts can be posted to your channel.
MetricShot
metric card posting		 An image of the store metric card the extension renders locally. The Workvivo channel you choose, at the moment you choose it. Posting the card is the action you asked for.

About the Workvivo access token

This is an authentication credential and is treated as one. It is your own token, issued to your own Workvivo session. It is transmitted over HTTPS to the QRCallBox backend, held only so scan alerts can be posted to your store's channel, and replaced each time the extension refreshes it. It is not shared with anyone else and is not used to access anything other than the channel you configured. If you do not enable the QRCallBox module, no token is ever sent.

What stays on your device

Everything else. Specifically, and without exception:

  • Case lists, ORC monitoring results, Spark order fraud reviews, digital lock events, claims records and store metrics captured from dashboards.
  • Report drafts, exported PDFs and CSVs — these are written to your Downloads folder and go nowhere else.
  • Module settings and preferences.
  • Session information used to tell whether you are still signed in to a dashboard.

This data is stored using the browser's local extension storage. It is removed when you uninstall the extension.

What the extension never does

  • It does not collect your browsing history, and does not read pages other than the specific dashboards named in its permissions.
  • It does not sell or rent data to anyone, and never has.
  • It does not transfer data to third parties except as described in the table above.
  • It does not use your data for advertising, retargeting, credit scoring, or lending decisions.
  • It does not ask for, store, or transmit your Walmart password. Where the extension needs an authenticated session it uses the one your browser already holds.
  • It does not include analytics SDKs, advertising SDKs, or third-party trackers of any kind.

Credentials and sessions

Several modules read an authorisation header or session cookie that your browser is already sending to a site you are signed in to, and reuse it to fetch the same data the page would have fetched. This is done so the extension never has to ask you for a password. Except for the Workvivo token described above, these credentials stay on your device and are used only against the site that issued them.

Permissions

The extension requests access only to the specific internal Walmart systems and licensed vendor tools an Asset Protection investigator already uses — case visibility, Auror, Appriss Retail, Power BI, Tableau, Enviance, Workvivo and similar. Broad wildcard access to walmart.com was deliberately removed in favour of naming each host.

The extension also uses Chrome's debugger permission, in one module only, to keep a background single-sign-on redirect from stalling and to submit the sign-in form on Walmart-managed devices where the ordinary scripting API does not work. It is attached only to that sign-in flow, always detached afterwards, and never used to read page content or network traffic.

Data retention and deletion

Data held on your device is deleted when you remove the extension, and can be cleared at any time from the extension's own settings.

For the records described in the table above, contact the developer at the address below to request access to or deletion of data associated with you. Requests are handled within 30 days.

Children

APAISuite is a workplace tool for Walmart Asset Protection personnel. It is not directed to children and is not intended for anyone under 18.

Limited Use

APAISuite's use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide and improve the features described here, is not transferred except as described above, is not used for advertising, and is not sold.

Changes to this policy

If what the extension collects changes, this page is updated and the date at the top changes with it. Material changes are also called out in the extension's release notes.
