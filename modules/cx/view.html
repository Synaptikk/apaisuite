A 52-week first pull is about 8,000 comments in eight requests, roughly two minutes. After that a Refresh only reads what is new.

Only needed for The read. Sign in opens the gateway's own sign-in page and picks the token up automatically when you finish — the same page and the same token Code Puppy uses, so signing in here does not disturb it.

That page may flash “Authentication failed — make sure your CLI is running”. Ignore it. It is trying to hand the token to the Code Puppy CLI on port 8090; if your CLI is not running that hand-off fails, but this extension has already read the token and will close the tab. The status above is what to go by.

The token is stored on this device only, is never sent anywhere except puppy-backend.walmart.com, and expires every few weeks; sign in again when it does.

Pick .code_puppy\puppy.cfg in your user folder and the token is read straight out of it. An extension cannot open files on its own — but it can read one you hand it, and that beats copying a 1,900-character token by hand.

Sent as x-puppy-version. The gateway refuses clients below a floor — and refuses a request with no version at all — answering with "your Code Puppy CLI is out of date" instead of a result. Measured 2026-09-25: 0.1.61 is blocked, 0.1.70 and above pass. Leave it blank to use the default; raise it if the gateway starts refusing again.
