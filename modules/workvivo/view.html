About QRCallBox

QRCallBox is a physical callbox replacement, saving thousands of dollars per store. Instead of installing wall-mounted intercoms, every department gets a printed QR poster. A customer scans the poster, a notification fires to the associates working that store, and the first responder claims it.

Notifications go down two parallel paths so a single dead phone or stale chat session never strands a customer:

  • FCM push to every on-shift associate's Android phone (the QRCallBox app). Works without any browser involvement.
  • Workvivo chat post in the store's QRCallBox channel, so anyone watching chat sees it too — and so response time gets tracked against the chat reply, not just the app claim.

Every scan creates an analytics record: who claimed it, how fast, which area, time-of-day patterns. The store manager dashboard at qrcallbox.com surfaces it all — top responders, busiest areas, response-time trends.

What this connector does

The Workvivo half of the system needs a fresh Sendbird chat token to post into your store's channel. Sendbird tokens issued through Walmart SSO can't be refreshed by a server — MFA can't be replayed. This module solves that by acting as a quiet courier:

  • Once an hour, it reads your live window.v2.chatConfig.access_token from any open workvivo.walmart.com tab.
  • It POSTs that token to your QRCallBox cloud function, authenticated by the API key you generated at qrcallbox.com → Workvivo tab.
  • QRCallBox stores the fresh token and, the moment a QR scan happens, opens a Sendbird WebSocket using it and posts the chat notification — all server-side, 24/7. The extension only needs to be running for the hourly refill, not for each individual scan.

Operation: as long as Chrome is your daily-driver browser and you have a workvivo.walmart.com tab open at least once a day, QRCallBox stays synced automatically — no panel visits, no re-pasting, no token expiry alerts to chase. The token never leaves Walmart-controlled hosts: workvivo.walmart.com → extension SW → qrcallbox.com (your own cloud function).
