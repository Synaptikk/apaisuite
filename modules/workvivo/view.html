Set up

  1. 1 Paste your QRCallBox API key

    Generate it at qrcallbox.com → Settings → Integrations → Workvivo notifications. It is shown once; paste it here.

  2. 2 Sign in to Workvivo in this browser

    The connector reads your chat token from an open Workvivo tab. Stay signed in and it opens Workvivo in the background whenever it needs a fresh token; you do not need to keep a tab open.

  3. 3 Pick your store's call channel

    Usually a group chat named "store number Customer Calls" with the team in it. Create it in Workvivo first if it does not exist. The list below is loaded by Refresh now.

How this works

QRCallBox replaces wall-mounted call boxes with printed QR posters. A customer scans one, every on-shift associate's phone gets a push, and the same alert is posted into the store's Workvivo chat so whoever is watching chat sees it too. Response time is tracked against the first chat reply.

Posting into Workvivo chat needs a Sendbird chat token. Tokens issued through Walmart SSO cannot be refreshed by a server, so this connector is the courier:

  • Once an hour it reads the live chat token from a Workvivo tab and sends it to qrcallbox.com with your API key. With no tab open it opens one in the background when the last refresh is more than six hours old.
  • If a scan post fails because the token died, qrcallbox.com pushes a refresh request to this browser and the connector answers within seconds.
  • If Workvivo is signed out, you get one desktop notification asking you to sign in.
  • QRCallBox stores the token and posts each scan itself, so scans are posted at 3am without any browser open. The token only travels workvivo.walmart.com → this extension → qrcallbox.com.
