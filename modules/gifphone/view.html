GIF Phone Setup

Turns a spare work phone into the reader that feeds the Digital Dashboard. You do the four things on the left; the button does the rest.

What you do

Once per phone, before you start

  1. GIF works on the phone. The phone is enrolled (Hub app says Compliant), GIF is installed in the work profile, and you've signed in to GIF once.
  2. The phone is on Wi-Fi and stays on it. Readings go straight from the phone to qrcallbox.com.
  3. Turn on USB debugging. Settings → About phone → Software information → tap Build number 7 times (enter the phone PIN if asked). Back out to Settings → Developer options → turn on USB debugging.
  4. Your QRCallBox key is in the suite. Open the Workvivo module once and save your key if it asks. Checking…

Then

  1. Plug the phone into this PC with a cable that carries data (not a charge-only cable). Unlock it.
  2. Press Set up phone, pick the phone in the list the browser shows, and press Connect.
  3. On the phone, tick Always allow from this computer and tap Allow.
  4. Wait for every step to go green (about 2 minutes). Leave the phone plugged in, face up. If GIF asks you to sign in, sign in. That's it.
If it gets stuck
  • The phone isn't in the browser's list: USB debugging is off, or the cable only charges. On the phone pull down the notification shade, tap the USB notice and pick File transfer; try another cable.
  • "Another program on this PC is using the phone": close Android Studio or any adb window, unplug and replug, press Set up again.
  • The phone never asked to Allow: unplug, replug, and unlock the phone. In Developer options, Revoke USB debugging authorisations then try again.
  • Install blocked: if the phone shows "Install anyway", tap it and press Set up again. A "work policy" error needs IT.
  • No first reading: look at the phone. A GIF sign-in, a "session expired" box or a Hub certificate message needs a person. Fix it and the readings start on their own.
  • Every step is safe to repeat, so pressing Set up phone again is always fine.
