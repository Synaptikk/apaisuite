SparkRisk

Pre-checkout timing analysis for Spark Shop & Deliver
How SparkRisk Works

What it does

SparkRisk identifies Spark delivery driver sessions with unusual pre-checkout timing patterns, flagging potential fraud or operational issues before items leave the store.

Scoring Model (v2)

Priority score based on three factors:

  • Excess Time — How much slower than expected for the basket size
  • Driver Deviation — Compared to this driver's personal baseline
  • Peer Percentile — Compared to context-matched peers (congestion, peak hours, batch size)

Workflow

  1. Extract WISMO data using the "Data Extraction" tool below
  2. Review high-priority sessions in the queue (score ≥ 45)
  3. Click a session to see register timestamp (for camera review) and order details
  4. Resolve real order numbers when needed for investigation
  5. Mark sessions as cleared, confirmed, or escalated

Privacy & Security

All data stored locally in browser IndexedDB. Real order IDs and driver names are visible but audit-logged. Never share extracted data outside authorized systems.
